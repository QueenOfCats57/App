🔗 Цепочки Pipes

Цепочка 1

Было: "{{ productName }}"

Стало: "{{ productName | uppercase | slice:0:10 }}"

"{{ productName }}" | uppercase | slice:0:10
→ Сначала в верхний регистр, потом обрезаем до 10 символов

Цепочка 2

Было: {{ createdAt }}

Стало: {{ createdAt | date:'fullDate' | uppercase }}

{{ createdAt }} | date:'fullDate' | uppercase
→ Сначала форматируем дату, потом в верхний регистр

⚙️ Собственные Pipes

1. TruncatePipe

Было: "{{ description }}"

Стало: "{{ description | truncate:25 }}"

text | truncate:25
→ Обрезает текст до 25 символов и добавляет "..."

2. PhoneFormatPipe

Было: 79161234567

Стало: {{ '79161234567' | phoneFormat }}

'79161234567' | phoneFormat
→ Форматирует номер: +7 916 123-45-67

3. RatingStarsPipe

Было: {{ rating }}

Стало: {{ rating | ratingStars:5 }}

{{ rating }} | ratingStars:5
→ Превращает число в звездочки: {{ rating | ratingStars:5 }}
